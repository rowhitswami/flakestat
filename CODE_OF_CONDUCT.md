# Code of conduct

## The short version

Be decent. Assume the other person is acting in good faith, argue about the
code rather than the person, and accept that "no" is a complete answer about
scope.

## What is expected

- Technical disagreement is welcome and is most of what happens here. Personal
  criticism is not the same thing.
- Bug reports that say a result is wrong are useful. This project exists because
  measurement is easy to get wrong, and a report that flakestat scored something
  incorrectly is the most valuable thing you can send.
- Maintainer time is finite. An unanswered issue is a queue, not a slight.

## What is not

Harassment, insults, demeaning comments, unwelcome attention, publishing private
information, and sustained disruption. Also: pressuring someone to keep working
on something, and reopening a scope decision repeatedly after it has been
answered.

## Enforcement

Report a problem through
[private vulnerability reporting](https://github.com/rowhitswami/flakestat/security/advisories/new)
if it involves anything sensitive, or by opening an issue if it does not.
Reports are handled by the maintainer, kept confidential, and answered.

Responses run from a private word, to editing or removing comments, to blocking
an account, depending on what happened and whether it continues.

## Scope

Applies in the repository, its issues and pull requests, and anywhere someone is
representing the project.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
rewritten to say what it actually means here.
